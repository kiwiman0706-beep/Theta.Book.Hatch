**Theta.Jisui.Viewer** — FullOCR の `.jisui`（jisui-1）をダブルクリックで開くビューアです（DSBooks の読書機能から NAS 機能を除いたもの）。

- `.jisui` を開くと目次（00_index.md）から読めます。章リンク、挿絵、読み上げ、文字サイズ・フォント（OS の明朝・ゴシック）、栞・メモが使えます
- 「原文 p.15」で原典PDFのそのページへ切り替え（PDF同梱・隣に置いたPDF のどちらも）。PDFの「本文へ」で戻れます
- `_digest.md` があれば、要約・マインドマップ・一問一答を表示します。自分の Gemini API キーで作ることもできます（送信前に確認画面）
- `.jisui` は書き換えません。読書位置などはアプリ側に保存します

## インストール

- **Windows**：`ThetaJisuiViewer-Setup-*.exe` を実行（管理者権限不要）。`.jisui` が関連付けられます。署名していないため「WindowsによってPCが保護されました」が出たら「詳細情報」→「実行」
- **Mac（Apple Silicon）**：`.dmg` を開いて「アプリケーション」へ。未公証のため初回は「システム設定 → プライバシーとセキュリティ」の「このまま開く」。以後 `.jisui` をダブルクリックで開けます

秀英体フォントは入っていません（FullOCR に同梱して配布するため）。
