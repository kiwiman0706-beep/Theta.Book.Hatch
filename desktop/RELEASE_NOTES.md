**DSBooks for Windows 0.2.2** — FullOCR の `.jisui`（自炊本）を開けるようになりました。前の版の上にそのままインストールできます（本・読書位置は引き継がれます）。

- 「端末の本を追加」で `.jisui` を選ぶと、コピーせずにその場で開きます。目次・章リンク・挿絵・「原文 p.N」（PDF同梱／隣のPDF）・ダイジェスト表示が使えます。本棚から削除しても元ファイルは消しません
- NAS 上の `.jisui` も1冊として本棚に出ます
- Markdown の挿絵（`.jisui` 内）を表示
- `.jisui` のダブルクリック起動は、別配布の Theta.Jisui.Viewer が担当します（DSBooks は関連付けしません）

**DSBooks for Windows 0.2.0** — 本を別ウインドウで開けるようになり、DeskHatchのドロワーとしても使えます。0.1.0の上にそのままインストールできます（本・読書位置は引き継がれます）。

## 0.2.0 の変更

- **本ごとに別ウインドウ**：本棚から本を開くと、本ごとに新しいウインドウが開きます。複数の本を並べて読めます。同じ本をもう一度開くと、そのウインドウが前に出ます。音声本は本棚のウインドウで再生します（ミニプレーヤー付き）。
- **DeskHatchのドロワー**：DeskHatchに `http://127.0.0.1:47817/` をドロワーとして追加すると、引き出しの中に本棚が出ます。本を選ぶと別ウインドウで開きます。下の「DeskHatchで使う」を参照。
- **どのウインドウでも同じ本棚**：本棚・読書位置・栞・設定はDSBooks本体で一元管理し、本のウインドウでページをめくると、本棚やドロワーの進捗もすぐ変わります。
- **バックグラウンド起動**：インストール時に「Windowsの起動時にバックグラウンドで起動する」を選ぶと、本棚を開かずに待機し、DeskHatchのドロワーからいつでも使えます。スタートメニューのDSBooksで本棚が前に出ます。終了は☰メニュー →「DSBooksを終了」。
- **Shuei Times を同梱**：Android版と同じフォントを入れました。
- **朗読の速度変更が効かない不具合を修正**：読み上げ中に速度を変えると、今の文の続きから新しい速度で読み直します。
- **ダウンロードの記録**：「前のダウンロードがキャンセルされる」報告の原因調査のため、`%LOCALAPPDATA%\DSBooks\download.log` に開始・待ち・キャンセル・完了を記録します（NASアドレスやログイン情報は書きません）。

## DeskHatchで使う

1. DSBooks を起動しておく（バックグラウンド起動でも可）。
2. DeskHatchの ☰メニュー →「設定」→「新規項目を追加」で、種類「ページ」、URL に `http://127.0.0.1:47817/` を入れる（幅は 480〜600 くらいがおすすめ）。
   ブラウザのアドレス欄からこのURLをDeskHatchのバーへドラッグし、クリップの「➕ ドロワーとして追加」でも追加できます。
3. ドロワーを開くと本棚が出ます。本を選ぶと DSBooks の別ウインドウで開きます。

## インストール

`DSBooks-Setup-*.exe` を実行（管理者権限は不要）。署名していないため「WindowsによってPCが保護されました」が出たら「詳細情報」→「実行」。持ち運び版は `*-windows-portable.zip`。Windows 10/11 標準の Microsoft Edge WebView2 を使います。

## まだできないこと

CBR（RAR）コミック、Chromecast・TV・ウィジェット、閉じている間のダウンロード、通知、自動更新、Mac版。

自動確認：Windowsのビルド環境でソース・exe・実ウインドウの起動とフォント同梱を確認。Linuxの実ブラウザで、別プロファイルのページ（ドロワー相当）と本のウインドウで本棚・読書位置が共有されること、本のウインドウの開閉・再表示、ページごとの応答の振り分け、朗読の速度変更を確認。**Windows実機での画面操作、DeskHatch上での表示、実NASは未確認**です。
