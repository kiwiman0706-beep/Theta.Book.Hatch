**DSBooks for Windows** の最初の版です。Android版と同じ本棚・読書画面をWindowsのウィンドウで動かし、表紙キャッシュ作成ツール（旧PCツール）も同じアプリに入れました。

## インストール

1. `DSBooks-Setup-*.exe` を実行（管理者権限は不要）。署名していないため「WindowsによってPCが保護されました」が出たら「詳細情報」→「実行」。
2. スタートメニューの **DSBooks** で本棚、**DSBooks ライブラリ管理（表紙キャッシュ）** で表紙キャッシュ作成ツールが起動します。アプリ内の☰メニュー →「ライブラリ管理（表紙キャッシュ作成）」からも開けます。
3. インストールせずに使う場合は `*-windows-portable.zip` を展開して `DSBooks.exe`。

Windows 10/11 標準の Microsoft Edge WebView2 を使います（通常は導入済み）。

## できること

- NASの登録・スキャン・本棚（☰メニュー、並べ替え・絞り込み、リスト表示など Android版0.9.3と同じ画面）
- NASからダウンロード（待ち行列・ダウンロード一覧・表紙の進捗表示）、PCの本の追加（ファイル選択）
- EPUB（縦書き・横書き、スワイプ方向の設定はマウスでは「次へ／前へ」とキーボードで代用）、PDF、CBZ、Markdown
- M4B/M4A の再生（保存済み・NASからストリーミング）、章、速度、スリープ
- 朗読：Windowsの日本語音声（Haruka など）で読み上げ
- 読書データの書き出し／取り込み、NAS自動同期（Android版と同じ `_DSBooksSync`）
- Esc キー・マウスの戻るボタン＝Androidの「戻る」

## まだできないこと（0.1.0）

- CBR（RAR）コミック、Chromecast・TV・ウィジェット
- アプリを閉じている間のダウンロード継続、通知、自動更新
- Shuei Times フォント（配布用ビルドに含めていません。明朝で表示）
- Mac版（同じ仕組みで今後対応）

## データ

本・読書位置・設定は `%LOCALAPPDATA%\DSBooks` に保存し、アンインストールしても残ります（☰メニュー →「データフォルダを開く」）。NASのログイン情報はWindowsのユーザー単位で暗号化（DPAPI）して保存します。Android版とは別の端末として扱われ、読書位置はNAS自動同期か読書データの書き出し／取り込みで共有します。

自動確認：Windowsのビルド環境で、ソースとビルド済み exe の両方を起動して本棚の配信と橋渡し機能を確認。Linux上で実ブラウザを使い、本の追加・EPUB/PDF/CBZ表示・表紙・NAS中継・ダウンロード待ち・音声の部分取得・ログイン情報保存を模擬NASで確認。**Windows実機での画面操作・実NASは未確認**です。
