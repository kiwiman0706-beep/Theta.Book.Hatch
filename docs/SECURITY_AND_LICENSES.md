# 秘密情報・個人情報・ライセンス

## 今回の分離

- 署名秘密鍵/パスワード、保存済みNAS認証情報、購入書籍の原本は収録しない。
- 初期0.2.0ソースには署名鍵と歴史的な直書きパスワードが見つかった。整理済み過去スナップショットでは鍵とbuild生成物を除外し、該当文字列を `[REDACTED_SIGNING_PASSWORD]` に置換した。実値はこの資料に転記しない。
- 現行 `build.sh` の環境変数名・鍵alias・鍵ファイルの期待パスは再現手順のため残す。秘密鍵そのものではない。
- 提供フォントは `private-assets/`、完成APKは `release-artifacts/` に分離。外側のZIPは個人用引き継ぎ資料であり、そのまま公開する前提ではない。
- 現行ソースの個人向け挨拶/接続先初期値はアプリの再現性のため残している。公開前に汎用化する。ソースをprivateで保管することと、安全な本番設定であることは別。

## ソフトウェアの権利

このアプリ独自部分に、所有者の許可なくMIT等のライセンスを新設していない。公開/再配布する場合は所有者が条件を決定する。第三者部分は `third_party/` のPOM・NOTICE・ライセンス資料と実際に固定された依存版を照合する。LibVLC、Junrar、AndroidX、Google Cast、PC用PyMuPDF等はそれぞれの条件に従う。

古い第三者資料が「バイナリ/ソース同梱」と記載していても、現在のソースZIPには依存バイナリ一式はない。APK配布時に必要なライセンス表示、対応ソースの提供、ライブラリ入替可能性などの義務を、その版のライセンスに沿って別途確認する。ここにある依存一覧だけで法的な完了を証明しない。

ShueiTimes.ttfの利用・再配布許諾は本会話から確認できない。書体名がわかることと再配布可能であることは同じではない。フォント入りAPKの公開可否も確認する。

## 実装上の注意

- Manifestはcleartext通信を許可している。Tailscale経路のHTTP利用を想定した既存仕様。一般インターネットへNAS認証情報を平文送信する設定を推奨しない。
- WebView bridge、ZIP/RARパス、外部ファイル共有、ローカルCast HTTP配信、diagnostic出力は継続レビュー対象。
- 任意の外部API（Gemini/Amazon等）へ書名/原本を自動送信する機能は未実装。追加時はユーザーの選択と取得元の条件を扱う。
- 診断は実際のメディア出力・接続成功と分離して報告し、認証情報を出力しない。

これはセキュリティ監査の完了証明ではない。今回の検査は梱包時の秘密鍵除外、既知秘密文字列の除去、ファイル整合性の確認。
