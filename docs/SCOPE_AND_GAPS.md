# 収録範囲と欠落

## 基準

2026-10-15時点。0.8.6-preview（versionCode 64）の保存済みソースとAPK、ROADMAP保存版38、見えている開発会話、保存済み過去資料を照合した。

## 収録したもの

- 現行AndroidのJava/HTML/CSS/JS、リソース、Manifest、build.sh、依存取得/パッケージングツール、依存定義・既存ライセンス資料。
- PC CLI/GUI・配布用構成。PC helper 0.3.0の本体3ファイルは現行tools/配布コピーと一致する。
- 現行元ソースの234ファイルの対応表・全SHA-256を `reference/source-baseline.json` に保存。READMEは履歴用へ移し新しい入口を作成、フォントは外側へ分離。それ以外の現行元ソースはハッシュを照合する。
- 回収できた0.4.8〜0.8.6の実機チェックリスト、既存tests/fixtures/notes、今回の検証記録。
- 現行版のAPK一つと提供フォント一つ（GitHub用フォルダの外）。署名鍵は別管理。
- 過去Androidソース：0.2.0-preview、0.4.8、0.4.9、0.5.0〜0.5.5、0.6.0〜0.6.2、0.7.0、0.8.0〜0.8.5。0.5.3は破損ZIPからの部分回収。他はZIPエントリのCRCを読み込み時に検査。
- PCツール0.1、GUI 0.2、PC helper 0.3.0、初期HTML/本棚モックアップ。
- 全74成果物の存在記録（artifact-inventory）。古いAPKの内容確認ではなく、ファイル名/保存時刻/容量のメタデータ。
- AI向け入口・依頼文、要望67項目、版履歴、課題、設計/データ形式、ビルド/配布/テスト案内、軽量CI、整合性検査。

## 同梱しないもの・回収できていないもの

|対象|理由/留保|
|---|---|
|署名鍵・パスワード|更新に必要だが公開用ソースに混入させない。別途安全に引き継ぐ|
|実NAS保存認証情報、個人ライブラリDB|実機のデータ。ソースに含まれていない|
|購入EPUB/PDF/M4B等の原本|今回使える原本なし。ユーザー画像/報告は経緯として要約|
|アップロード画像の元JPG|会話では見えるが指定ローカルパスに原本がない。画像バイトを再作成したとは言わない|
|全会話の完全逐語録・過去AI回答全件|現在取得できる会話/資料で要約した。過去のツール実行全ログや隠れた状態はない|
|過去のGit履歴、GitHub remote|確認できていない。新規取り込みが必要|
|旧APK一式|最新版のみ実体を収録。旧版はメタデータ索引|
|0.1.x〜0.4.7の各版ソース|0.2.0-preview以外の単独ソースを今回の検索から回収できていない|
|0.3.7の配布物|会話に言及はあるが今回の検索に該当成果物なし|
|0.2.0の別名ソース、0.8.0作業中checkpoint|メタデータはあるが完成版/代表ソースを採用し重複取得していない|
|0.5.3の完全ソースZIP|元ファイル自体がZIPとして開けない。CRC検証済みの先頭エントリだけ救出|
|SDK/JDK/buildキャッシュ/AAR/JAR/so|取得手順とハッシュで再構成。古いスナップショットからも除外|
|Windows Setup.exe / Mac閲覧アプリ / IPA|生成用PC構成はあるが完成成果物はない|
|GitHub Actions上の実行結果|設定を用意しただけ。実行済みとはしない|
|Cast/TV/Auto/NAS/音声出力の全面実機完了|コード/一部機械テストはあるが実機確認待ちを含む|

## 出典の優先順位

現行実装＋現行検証結果 → 利用者の具体的報告 → 当該版チェックリスト → ROADMAP/累積README → ファイル名だけのメタデータ。矛盾時は隠さず記録する。ROADMAPには歴史的な未実装記述も残るため、現状はCURRENT_STATEと併読する。

「漏れがないように」は、入手できた情報を網羅して所在/未確認/欠落を示す方針で実現した。入手できないソースや過去の正確な変更内容を作り上げてはいない。
