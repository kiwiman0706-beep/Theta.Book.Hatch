# FullOCR ページアンカー仕様 `fullocr-1`（DSBooks 側の写し）

FullOCR 側の仕様書を利用者から受け取り（2026-10-19）、DSBooks 0.9.5 で読み取り側を実装した。正本は FullOCR 側にある。ここには要点と、DSBooks での実装の対応を記す。

## 仕様の要点

- 本文中のマーカー：`<!-- fullocr:page pdf=23 print="15" -->`。各PDFページの最初の可視ブロックの直前に、独立した1行で入り、前後は空行。
  - `pdf`：必須。原PDFの物理ページ（1始まり）で、文書内で単調増加する。欠番はありうる。
  - `print`：任意。印刷ページ番号（`"15"`、前付けは `"iv"`）。
  - 抽出の正規表現：`<!--\s*fullocr:page\s+pdf=(\d+)(?:\s+print="([^"]*)")?\s*-->`
- `%%…%%` で隠した印刷目次の中でも、マーカーは出力される。見出し行には混ざらない。
- `00_index.md` の front-matter：
  - `page_anchors: fullocr-1`：スキームの宣言。
  - `pdf_file`：同じフォルダにある原PDFのファイル名。
  - `page_offset`：`印刷ページ = pdf - offset`。3ページ以上で一致した時だけ出力される。
  - 章ごとに分割された本では、front-matter は `00_index.md` にだけ付き、フォルダ全体の設定になる。
- リーダーの動作：
  - 現在位置の直前のマーカーの `pdf` で、PDFを開く。
  - 表示は `print`、なければ `pdf - page_offset`、どちらもなければ `p.N（PDF通し）`。
  - 逆方向は、PDFのページ N に対して `pdf <= N` の直近マーカーへ移動する。
- 後方互換：将来の版は識別子を `fullocr-2` に上げる。`pdf` 必須と `<!-- fullocr:page ... -->` の構文は保たれる。

## DSBooks の実装（`app/src/main/assets/md-page-anchors.js`）

|仕様|実装|
|---|---|
|マーカーを不可視に|読み込み時に印へ置き換え、高さ0の `.fo-anchor` 要素として本文に残す。見出しは変えない|
|`%%…%%`|隠すが、中のマーカーは残す（隠し目次付近からも飛べる）|
|front-matter|表示しない。`page_anchors` / `pdf_file` / `page_offset` を読む。章ファイルを開いた時は、同じNASフォルダの `00_index.md` を読む（端末に保存済みの場合のみ。未保存なら下の推定になる）|
|原PDFの特定|`pdf_file` と同名の本（同じフォルダ優先、なければ蔵書全体）。宣言が読めない時は、同じフォルダの `*_text.pdf`、またはそのフォルダ唯一のPDF|
|「原文」|読書画面上部の「原文 p.15」。押すと、画面上端より上で直近のマーカー（二分探索）の `pdf` で、PDFを `pdf-1` ページ目（0始まり）から開く。PDFが未保存ならダウンロード画面を出し、保存後にそのページで開く|
|現在ページの表示|スクロールに合わせて `print` → `pdf - page_offset` → `p.N（PDF通し）` の順に表示|
|PDF→MD|PDFの読書画面に「本文へ」。同じフォルダの保存済みMarkdown（章ファイル全部）のマーカーから `pdf <= 現在ページ` の直近を探し、そのファイルのその位置を開く。「本文へ」が出るのは、MDから開いた時と、同じフォルダの `00_index.md` が `page_anchors` を宣言し、`pdf_file` がこのPDFを指す時|
|その他|一般のHTMLコメントは非表示。`[[ファイル#見出し\|別名]]` は同じフォルダのMarkdownを開いて見出しへ移動する。`![[画像]]` は［画像：名前］と表示|

制約：
- Markdown の読み込みは4MBまで（従来どおり）。
- 位置の判定は画面上端の24px下までを含む。
- 見開き（2up）は区別しない（仕様どおり）。

テスト：`tests/md-anchors-0.9.5.cjs`（模擬ブリッジ）。実機・実際の FullOCR 出力での確認は `CHECKLIST_DEVICE_0.9.5.md`。
