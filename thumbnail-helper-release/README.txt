DSBooks 表紙キャッシュ作成ツール（Windows GUI）

インストール
1. ZIPを展開します。
2. Python 3.10以降がなければ先にインストールします。
3. setup.batをダブルクリックします。
   必要な画像処理部品が入り、スタートメニューに「DSBooks 表紙キャッシュ」が追加されます。
4. スタートメニューから起動します。
アンインストールはuninstall.batです。NAS上に生成した表紙キャッシュは残します。

使い方
1. 「フォルダを選択」で、Windowsから見えるNASの蔵書フォルダを選びます。
2. 同じ場所のDSMパスを入力します。
   例: PC上 Z:\8Books\⑧カメラ
       DSM   /8Books/⑧カメラ
3. 「表紙キャッシュを作成」を押します。
4. 完了したらDSBooksでNASを同期します。

フォルダ選択・DSMパスは次回起動時も記憶されます。生成先は選択フォルダ内の _DSBooksCache です。
PDFの先頭ページ、ePubの埋め込み表紙、M4A/M4Bの埋め込み画像を軽量JPEGにします。
元の本は読み取りのみで変更せず、外部サイトへも接続しません。
サイズと更新日時が同じ本は再生成せず、削除済み表紙のキャッシュは整理します。
表紙が本に含まれない場合は、DSBooksの文字入りカードが表示されます。

通常のsetup.batはPython 3とネット接続を使って部品を準備します。
インストール後はスタートメニューからGUIを起動できます。通常の利用にInno Setupは不要です。

Setup.exeを作る場合
WindowsにPython 3.10以降とInno Setup 6を入れ、build-windows-installer.batを実行してください。
dist-installer内にDSBooks-Thumbnail-Helper-Setup-0.1.0.exeが作成されます。


0.3.0 追加：安定した本IDとObsidian互換メタデータ
生成後「メタデータフォルダを開く」で本ごとのMarkdownを編集できます。
series（シリーズ）、volume（巻数）、tags（タグ）を編集して再生成してください。
bookIdは変更しないでください。本文には自由にメモを追加できます。
同じ走査範囲内での改名・移動は内容ハッシュから照合します。
Android 0.5.0の設定→読書データ／PC索引を取り込むで、生成したcatalog.jsonを選びます。
既存のAndroid蔵書にID・シリーズ・タグを反映します。NASの走査と表紙取得は従来どおりです。
原本ファイルは変更しません。初回は全体のハッシュ計算で時間がかかる場合があります。
このZIPはsetup.bat付きGUIです。ビルド済みSetup.exeは含みません。
