# 0.8.2 自動検証

- 添付実例EPUB（76,446,369 bytes）を実装したJavaパーサーで全196ページ読込。全ページに画像1枚、右開きの検出、SVGラッパーからの原画像抽出に成功。書籍本体は配布ソースには含めない。
- ComicContentTest.java：自作の3ページ画像でCBZ、圧縮RAR4／RAR5、それぞれソリッド／通常アーカイブを作成。画像バイトの一致、page1/page2/page10の自然順、末尾→先頭などランダム読込を確認。パスワード付きは説明付きエラーになる。
- comic-ui-0.8.2.cjs：実例EPUBの画像（1055×1499px）をWeb UIで表示。画面内フィット、拡大、拡大中スワイプの抑止、右／左開き、再開を確認。CBR UIの非同期表示・ページ移動・栞／JSON位置・戻る／再開・読了、Comicフィルター、NASからのCBZ／CBR分類も確認。
- ui-smoke.cjs：通常EPUBのページ送り、再開、文字設定、検索、回転、栞、設定の回帰確認。
- speech-follow-0.8.0.cjs：小説EPUBの朗読追従・強調・現在ページ開始・ルビ・再開の回帰確認。
- scan-scope-0.8.1.cjs：対象外フォルダの除外、保存済み／記録保持、0件・通信失敗時の保護の回帰確認。
- Android SDK 35でコンパイル、署名v2/v3を確認。旧版と同一証明書でversionCodeを60へ更新。
- 未検証：Android実機、実NAS、実端末SDカード、他アプリでの共有受信、CBR全圧縮方式の網羅。

Javaテストにはユーザーの実例EPUBと自作アーカイブが必要。書籍・RAR生成用バイナリは配布しない。自作の小さなアーカイブは tests/fixtures/comics に保存。
